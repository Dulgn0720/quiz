Production орчны бүх бүрэлдэхүүн. Хэрэглэгчид үзүүлэх үйлчилгээ.

---

## 3. Системийн бүрэлдэхүүн ба хамаарал

### 3.1 Дотоод бүрэлдэхүүн

1. **Мобайл апп** — iOS, Android. Дэлгүүрээр тараагдана
2. **API сервер** — Go, Docker контейнер, 1323 порт
3. **MongoDB** — `retail` өгөгдлийн сан, 33 коллекц
4. **MinIO** — 6 bucket, файл хадгалалт
5. **Вэб** — Next.js

### 3.2 Гадаад хамаарал

6. **QPay** — төлбөр. Зогсвол худалдан авалт бүрэн зогсоно
7. **MIIS** — даатгалын мэдээллийн систем. Зогсвол гэрээ бүртгэгдэхгүй
8. **AISYS** — үндсэн даатгалын систем. Зогсвол гэрээ синхрончлогдохгүй
9. **DAN** — иргэний нэвтрэлт. Зогсвол баталгаажуулалт зогсоно
10. **XYP** — төрийн мэдээлэл солилцоо
11. **Odoo** — дотоод удирдлагын систем
12. **Zuragu** — үнэлгээний үйлчилгээ
13. **SMS үйлчилгээ** — нэг удаагийн код. Зогсвол шинэ нэвтрэлт зогсоно
14. **SMTP** — и-мэйл нэг удаагийн код
15. **Firebase** — түлхэлтийн мэдэгдэл
16. **Sentry** — алдааны бүртгэл. Зогсвол үйлчилгээ үргэлжилнэ
17. **Telegram** — сэрэмжлүүлэг. Зогсвол үйлчилгээ үргэлжилнэ

### 3.3 Эгзэгтэй зам

18. **Нэвтрэх**: Апп → API → MongoDB → SMS үйлчилгээ
19. **Худалдан авах**: Апп → API → MongoDB → MIIS → QPay → AISYS
20. **Гэрээ харах**: Апп → API → MongoDB → MinIO

**Тайлбар**: §19-д зургаан бүрэлдэхүүн дараалан оролцоно. Аль нэг нь зогсвол худалдан авалт бүрэн зогсоно.
