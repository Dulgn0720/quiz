# Quiz Pro

Динамик quiz систем: ямар ч өгөгдөл (JSON / CSV) оруулаад, санамсаргүй холиж, тойрог, оноо, түвшинтэйгээр тоглоно. Build хэрэггүй, цэвэр HTML/CSS/JS.

## Ажиллуулах

```bash
npm start          # http://localhost:5174 (эсвэл: python3 -m http.server)
npm test           # engine-ийн тестүүд (Node 18+)
```

`index.html`-ийг шууд `file://`-аар нээвэл ES module ачаалагдахгүй тул заавал жижиг сервер ашиглана. GitHub Pages дээр шууд байршуулж болно.

## Боломжууд

- **Ямар ч өгөгдөл** — JSON эсвэл CSV (Excel/Sheets-ээс экспорт хийсэн, `,` `;` tab тусгаарлагч) оруулна, файлаар эсвэл хуулж тавина. Алдаатай мөр бүрийг дугаартай нь харуулна. Олон сан хадгалж, сольж, JSON-оор татаж авна.
- **4 төрлийн асуулт** — нэг сонголт, олон сонголт, үнэн/худал, бичгээр хариулах (том/жижиг үсэг, цэг таслал, илүү зай тооцохгүй).
- **Холих** — Fisher–Yates (хазайлтгүй) алгоритм. Асуулт ба сонголтыг тусад нь холино; зөв хариултыг индексээр биш ID-аар хадгалдаг тул холисны дараа ч зөв хэвээр. **Seed** өгвөл яг ижил дарааллыг давтана.
- **Тойрог** — асуултыг тойрогт тэгш хуваана. "Шат ахих" горимд тойрог бүр өмнөхөөсөө хэцүү болно. Тойрог давах босго (50–80%) тавьж болно.
- **Оноо**
  - суурь: хүндрэл × 100 (эсвэл асуултын `points`)
  - хурдны бонус: үлдсэн хугацаанд хамааран суурийн +50% хүртэл
  - цуврал: дараалсан зөв хариулт бүрт ×0.25, дээд тал нь ×2
  - олон сонголтод хэсэгчилсэн оноо (буруу сонголт хасагдана)
  - төгс тойрог: +200 × тойргийн дугаар
  - 50/50 ашигласан асуултын оноо ×0.5
- **Тусламж** — 50/50, +15 секунд, алгасах (алгассан асуулт нарийвчлалд тооцогдохгүй).
- **Тоглогчийн түвшин** — XP хуримтлагдаж түвшин ахина (2-т 500, 3-т 1500, 4-т 3000 XP …), цол: Шинэхэн → Домог.
- **Үр дүн** — S/A/B/C/D үнэлгээ, тойрог бүрийн задаргаа, хариулт бүрийн тойм, тэргүүлэгчдийн жагсаалт.
- Гарын товч (1–9, Enter), гар утсанд тохирсон, dark/light горим.

## Өгөгдлийн формат

```json
[
  { "question": "Монголын нийслэл?", "options": ["Дархан", "Улаанбаатар"], "answer": "Улаанбаатар",
    "category": "Газарзүй", "difficulty": "easy", "explanation": "…" },
  { "question": "Аль нь тэгш тоо вэ?", "options": ["2", "3", "4"], "answer": ["2", "4"] },
  { "question": "Нар бол од.", "answer": true },
  { "question": "2 + 2 = ?", "type": "text", "answer": ["4", "дөрөв"], "time": 10 }
]
```

| Талбар | Тайлбар |
| --- | --- |
| `question` | Асуулт (заавал) |
| `options` | Сонголтууд. CSV-д `a\|b\|c` |
| `answer` | Сонголтын текст, 0-ээс эхэлсэн индекс, үсэг (`A`, `B`…), олон бол массив / `a\|b`; үнэн/худал бол `true`/`false`; бичгээр бол хүлээн авах хариултууд |
| `type` | `single`, `multiple`, `boolean`, `text` — заахгүй бол автоматаар таньна |
| `difficulty` | `1`–`3`, `easy/medium/hard`, `хялбар/дунд/хэцүү` (анхдагч 1) |
| `category`, `explanation`, `time`, `points`, `id` | Заавал биш |

CSV жишээ:

```csv
question,options,answer,difficulty,category,type
Монголын нийслэл?,Дархан|Улаанбаатар|Эрдэнэт,Улаанбаатар,easy,Газарзүй,
Аль нь тэгш тоо вэ?,2|3|4,2|4,medium,Математик,multiple
Нар бол од.,,true,easy,Шинжлэх ухаан,boolean
```
