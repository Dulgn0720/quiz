Асуултын сан

JSON эсвэл CSV хэлбэрээр ямар ч өгөгдөл оруулна. Excel/Google Sheets-ээс CSV-ээр гаргаж болно.

Шинэ сан

Өгөгдлийн формат
  • question — асуулт (заавал)
  • options — сонголтууд. CSV-д a|b|c гэж тусгаарлана
  • answer — зөв хариулт: сонголтын текст, индекс (0-ээс), үсэг (A, B…), олон бол массив / a|b, үнэн/худал бол true/false, бичгээр бол хүлээн авах хариултууд
  • type — single, multiple, boolean, text (заахгүй бол автоматаар таньна)
  • difficulty — 1–3 эсвэл easy/medium/hard, хялбар/дунд/хэцүү
  • category, explanation, time (сек), points — заавал биш
